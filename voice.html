🎤 Voice in English Grammar

Active Voice (सक्रिय वाच्य)

Structure:
Subject + Verb + Object

Example:
Ram writes a letter.
(राम एक पत्र लिखता है।)

Passive Voice (कर्मवाच्य)

Structure:
Object + is/am/are + V3 + by + Subject

Example:
A letter is written by Ram.
(एक पत्र राम द्वारा लिखा जाता है।)

🔹 Active से Passive Voice बदलने के नियम

Active Voice Structure Passive Voice Structure
Subject + Verb + Object Object + is/am/are + V3 + by + Subject
Subject + was/were + V2 + Object Object + was/were + V3 + by + Subject
Subject + has/have + V3 + Object Object + has/have been + V3 + by + Subject

🔸 Passive Voice कब उपयोग करें?

1. जब कर्ता अज्ञात हो:

"The window was broken."
(खिड़की तोड़ी गई।)

2. जब कर्म ज्यादा महत्वपूर्ण हो:

"The bridge was built in 1980."
(यह पुल 1980 में बनाया गया।)

3. जब हम प्रक्रिया पर ध्यान देना चाहें:

"The homework is being checked."
(होमवर्क की जांच की जा रही है।)

✅ Tense-wise Active & Passive Voice Table

🔹 Tense 🟢 Active Voice 🔵 Passive Voice 📘 Hindi Meaning
✅ Present Simple He writes a letter. A letter is written by him. वह एक पत्र लिखता है।
✅ Present Continuous He is writing a letter. A letter is being written by him. वह एक पत्र लिख रहा है।
✅ Present Perfect He has written a letter. A letter has been written by him. उसने एक पत्र लिखा है।
🔙 Past Simple He wrote a letter. A letter was written by him. उसने एक पत्र लिखा।
🔙 Past Continuous He was writing a letter. A letter was being written by him. वह एक पत्र लिख रहा था।
🔙 Past Perfect He had written a letter. A letter had been written by him. उसने एक पत्र लिख लिया था।
🔜 Future Simple He will write a letter. A letter will be written by him. वह एक पत्र लिखेगा।
🔜 Future Perfect He will have written a letter. A letter will have been written by him. वह एक पत्र लिख चुका होगा।

🔴 Tense के वे 4 रूप जिनमें Passive Voice नहीं बनाया जाता

🔢 क्रम 🔹 Tense Name ❌ Passive बनता है क्या? 📌 कारण
1️⃣ Present Perfect Continuous Tense ❌ नहीं बनता Structure बहुत awkward होता है: "has been being written" आदि
2️⃣ Past Perfect Continuous Tense ❌ नहीं बनता "had been being written" – बहुत complex और प्रयोग में नहीं
3️⃣ Future Continuous Tense ❌ नहीं बनता "will be being written" – grammatically possible but not used practically
4️⃣ Future Perfect Continuous Tense ❌ नहीं बनता बहुत ही कठिन और अप्राकृतिक बनावट होती है

📘 Active & Passive Voice – Tense-wise Formulas

🔢 🔹 Tense Name ✅ Active Voice Formula 🔄 Passive Voice Formula
1️⃣ Present Simple Subject + V¹ + Object Object + is/am/are + V³ + by + Subject
2️⃣ Present Continuous Subject + is/am/are + V¹+ing + Object Object + is/am/are + being + V³ + by + Subject
3️⃣ Present Perfect Subject + has/have + V³ + Object Object + has/have been + V³ + by + Subject
4️⃣ Present Perfect Continuous Subject + has/have been + V¹+ing + Object ❌ Passive नहीं बनता
5️⃣ Past Simple Subject + V² + Object Object + was/were + V³ + by + Subject
6️⃣ Past Continuous Subject + was/were + V¹+ing + Object Object + was/were + being + V³ + by + Subject
7️⃣ Past Perfect Subject + had + V³ + Object Object + had been + V³ + by + Subject
8️⃣ Past Perfect Continuous Subject + had been + V¹+ing + Object ❌ Passive नहीं बनता
9️⃣ Future Simple Subject + will/shall + V¹ + Object Object + will/shall be + V³ + by + Subject
🔟 Future Continuous Subject + will be + V¹+ing + Object ❌ Passive नहीं बनता
1️⃣1️⃣ Future Perfect Subject + will have + V³ + Object Object + will have been + V³ + by + Subject
1️⃣2️⃣ Future Perfect Continuous Subject + will have been + V¹+ing + Object ❌ Passive नहीं बनता
