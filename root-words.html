Root Word क्या होते हैं?

Root word एक ऐसा मूल शब्द होता है जिससे नए शब्द बनाए जाते हैं। इसमें prefix (पूर्व रूप) और suffix (उत्तर रूप) नहीं होते।

Prefix और Suffix क्या होते हैं?

🔹 Prefix (पूर्व-प्रत्यय)

Prefix वह भाग होता है जो किसी शब्द के शुरुआत में जुड़ता है और उसका अर्थ बदल देता है।

Un + Happy = Unhappy → "Un" का अर्थ: नहीं

Re + Play = Replay → "Re" का अर्थ: दोबारा

🔹 Suffix (उत्तर-प्रत्यय)

Suffix वह भाग होता है जो किसी शब्द के अंत में जुड़ता है और उस शब्द का प्रकार (noun, verb, adjective) बदल देता है।

Teach + er = Teacher → "er" का अर्थ: करने वाला

Kind + ness = Kindness → "ness" का अर्थ: भावना/भाव

1. Root Word: Act (करना)

React = Re + Act → फिर से करना

Actor = Act + or → करने वाला

2. Root Word: Form (रूप देना / आकार देना)

Transform = Trans + Form → रूपांतरण करना

Formation = Form + ation → निर्माण

3. Root Word: Port (ले जाना)

Export = Ex + Port → बाहर ले जाना

Import = Im + Port → अंदर लाना

Portable = Port + able → जो ले जाया जा सके

4. Root Word: Dict (बोलना)

Predict = Pre + Dict → पहले से कहना

Dictionary = Dict + ionary → शब्दकोश (जहाँ शब्दों के अर्थ कहे गए हों)

5. Root Word: Spect (देखना)

Inspect = In + Spect → निरीक्षण करना

Spectator = Spect + ator → देखने वाला
